# Страницы Арины

Учебные прототипы страниц. Всё, что лежит здесь, **видно всем в интернете**.

- Готовые страницы кладём в `p/` — каждая своей папкой: `p/название/index.html`.
- Ссылка получается такая: `https://brimtv.github.io/arina-pages/p/название/`
- Черновики и всё, что не для чужих глаз, остаются в `~/projects/learn/work/`.

## Как выложить

    cd ~/projects/pages
    git add .
    git commit -m "что добавила"
    git push

Через минуту страница обновится по ссылке.
